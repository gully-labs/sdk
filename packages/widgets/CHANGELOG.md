# Changelog

## 0.1.0 - 2026-10-30

- First release of `@gullylabs/widgets`: the tracker client, the Holder Map client with `<HolderMap>`, and the tracker widget loader with `<GullyWidget>`, merged from `@gullylabs/tracker` 0.1.0, `@gullylabs/holders` 0.1.0 and `@gullylabs/widget` 0.1.0 (same APIs).
- Holder Map: Gully Chain (`gully`, chain id 485590) is a supported chain.
- ESM and CommonJS builds with TypeScript types for every entry.
