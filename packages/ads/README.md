# @gullylabs/ads (renamed)

This package is now **`@swoopads/sdk`** (Swoop Ads). It stays as a thin re-export so existing imports keep working:

```ts
import { GullyAds } from '@gullylabs/ads' // same as: import { GullyAds } from '@swoopads/sdk'
```

New code should install `@swoopads/sdk`. See https://docs.swoopads.xyz/sdk/. MIT. Built and run by Gully Labs.
